# Эмулятор языка оболочки ОС (Вариант №5)

## Общее описание проекта
Данный проект представляет собой консольный эмулятор (CLI), имитирующий работу командной строки UNIX-подобной операционной системы. Приложение функционирует в интерактивном режиме (REPL), обрабатывает пользовательский ввод, поддерживает раскрытие системных переменных окружения, а также оперирует изолированной виртуальной файловой системой (VFS), развернутой непосредственно в оперативной памяти компьютера.

**Спецификация варианта №5:**
- **Интерфейс:** Консольный (CLI) с отображением имени файловой системы в приглашении к вводу.
- **Особенности парсера:** Поддержка раскрытия UNIX-переменных окружения (например, `$HOME`, `$USERPROFILE`).
- **Источник VFS:** Локальная директория на диске пользователя, загружаемая в память без изменения исходных файлов.
- **Основные команды:** `ls`, `cd`, `tree`, `uname`, `exit`.
- **Дополнительные команды (in-memory):** `cp`.

## Описание всех функций и настроек

### 1. Ядро системы и REPL-цикл
- **Интерактивный диалог:** Непрерывный цикл ожидания ввода. Приглашение имеет стандартизированный вид: `[имя_vfs]$ `.
- **Парсинг и обработка путей:** Реализован интеллектуальный разбор строки. Обратные слэши путей Windows (`\`) безопасно экранируются и приводятся к единому стандарту, предотвращая потерю символов при обработке модулем `shlex`.
- **Устойчивость к сбоям:** Перехватываются сигналы экстренного завершения (`Ctrl+C`, `Ctrl+D`) и синтаксические ошибки (например, незакрытые кавычки), предотвращая аварийное падение эмулятора.

### 2. Модуль конфигурации (Этап 2)
Запуск приложения гибко настраивается через параметры командной строки:
- `--vfs`: Абсолютный или относительный путь к локальной директории, которая послужит корнем VFS.
- `--script`: Путь к стартовому текстовому скрипту, содержащему последовательность команд для автоматического исполнения.

### 3. Виртуальная файловая система (VFS) (Этап 3)
- **Изоляция:** При старте эмулятора древовидная структура указанной директории считывается в оперативную память. 
- **Безопасность:** Все последующие операции удаления, перемещения или копирования происходят исключительно в структурах данных в памяти (In-Memory VFS). Физические файлы на жестком диске пользователя никак не модифицируются.

### 4. Поддерживаемые команды (Этапы 1, 4, 5)
- `exit` — завершение работы эмулятора с корректным освобождением ресурсов и возвратом кода `0`.
- `ls` — вывод содержимого текущей виртуальной директории (заглушка на Этапе 1, полноценная логика на Этапе 4).
- `cd <путь>` — смена текущего рабочего каталога внутри VFS с валидацией существования пути.
- `tree` — рекурсивный вывод дерева каталогов и файлов VFS в графическом текстовом формате.
- `uname` — вывод информации о системе (эмулируемое имя ядра, сетевой узел, релиз оболочки).
- `cp <источник> <приемник>` — копирование виртуального файла или папки в памяти.

## Инструкции по сборке и запуску

### Системные требования
- **Язык реализации:** Python версии 3.10 или выше.
- **Зависимости:** Проект написан с использованием стандартной библиотеки Python, установка сторонних пакетов (pip) не требуется.

### Запуск эмулятора в интерактивном режиме
Для запуска введите в терминале команду, указав путь к корневой папке эмулируемой файловой системы:
```bash
python src/main.py --vfs ./my_virtual_disk
```

### Запуск со стартовым скриптом (Пакетный режим)
Если необходимо автоматически выполнить цепочку команд при запуске приложения:
```bash
python src/main.py --vfs ./my_virtual_disk --script ./scripts/start.txt
```

### Использование готовых скриптов автоматизации
В корне проекта подготовлены автоматизированные сценарии для вашей операционной системы:
- **Для Windows:** Запустите файл `run.bat` двойным кликом или через cmd.
- **Для Linux/macOS:** Выполните в консоли:
  ```bash
  chmod +x run.sh
  ./run.sh
  ```

## Тестирование и примеры использования

### Запуск автоматических тестов
Для проверки работоспособности всех модулей, парсера и команд запустите команду из корня репозитория:
```bash
python -m unittest discover -s tests
```

### Примеры работы в консоли эмулятора

**1. Успешный запуск и просмотр системы:**
```bash
[my_vfs]\$ uname
System: Linux | Node: vfs-emulator | Release: 1.0.0-variant5

[my_vfs]\$ tree
.
├── documents
│   └── report.txt
└── src
    └── main.py
```

**2. Навигация и копирование файлов (in-memory):**
```bash
[my_vfs]\$ cd documents
[my_vfs]\$ cp report.txt backup_report.txt
[my_vfs]\$ ls
report.txt  backup_report.txt
```

**3. Раскрытие переменных окружения и обработка ошибок:**
```bash
[my_vfs]$ echo $USERPROFILE
C:\Users\volko

[my_vfs]$ unknown_command --help
shell: command not found: unknown_command

[my_vfs]$ cd folder_that_does_not_exist
cd: no such file or directory: folder_that_does_not_exist

[my_vfs]$ exit
```
