# Эмулятор оболочки ОС (Вариант №5, Этап 1)

Прототип эмулятора командной строки.

## Функции и настройки
- Приглашение к вводу содержит имя VFS ([my_vfs]$ ).
- Раскрытие системных переменных окружения (например, $USERNAME).
- Корректный разбор аргументов в кавычках.
- Вывод ошибок при вводе неизвестных команд или некорректных аргументов.
- Заглушки для команд ls и cd.
- Команда exit для завершения работы.

## Запуск проекта
Запуск приложения в ОС Windows:
```bash
run.bat
# или напрямую через интерпретатор:
python src/main.py
```
